# Full-Stack MERN URL Shortener

A full-stack URL shortening and link management application built with the MERN stack, featuring JWT authentication, custom short links, and click analytics.

## Tech Stack
- **Frontend:** React (Vite), Redux Toolkit, Tailwind CSS
- **Backend:** Node.js, Express.js, REST APIs
- **Database & Auth:** MongoDB, Mongoose, JWT Authentication

## Features
- Shorten long URLs into compact, shareable links with instant redirection
- User authentication (Register / Login) with protected dashboard routes
- Track link click counts and manage created URLs in a centralized dashboard
